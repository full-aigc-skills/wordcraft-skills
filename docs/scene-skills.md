# 场景技能候选

新增技能位于 skills/，独立技能源维护，插件本地候选按 scenario-candidates.json 校验。既有发布快照不变。当前完成内容与实际场景视觉验收分开；尚未逐场景完成用户素材验收。

- `wordcraft-business-proposal`：业务方案文档（目标、方案、计划和交付）
- `wordcraft-meeting-minutes`：会议纪要（讨论结论、决策与行动项）
- `wordcraft-research-report`：研究报告排版（摘要、章节、图表和参考来源）
- `wordcraft-resume-layout`：简历排版（经历、成果与紧凑版面）
- `wordcraft-document-style`：文档样式统一（标题、段落、列表和表格）
- `wordcraft-document-comparison`：文档修改核对（两个版本的文字与结构差异）
