# WordCraft 六类文档模板

首批提供会议纪要、工作周报、项目方案、需求说明、验收报告、业务函。增强会议纪要和项目方案两个既有技能，新增另四个独立技能。每种包含业务章节、字段填写指导、虚构输入样例、原生标题和可编辑表格；不让用户手工编写命令或JSON，Agent按任务资料填字段并调用工具。

模板适合新建文档。已打开内嵌编辑器时使用同一会话，先确认新建空文档；独立CLI生成不代表宿主画面同步。修改已有文档需定位目标范围，不以本模板全篇覆盖。

## 如何使用

用户可直接说“根据这些工作记录生成周报”“把会议记录整理为纪要”“根据需求和实测记录写验收报告，保留未通过项”。Agent选择对应文档技能，填写真实内容，缺失事实标待确认，生成可编辑DOCX及审阅PDF。样例中的示例文字仅用于演示与回归。

结构化验证见 [目录仓验证记录](https://github.com/partme-ai/full-aigc-plugins/blob/feature/REQ-20261016-wandl-craft-ui-skills/docs/wordcraft-document-templates-validation.json)。各技能本地的 template-command-evidence.json 记录方法、版本与本批验收范围。
